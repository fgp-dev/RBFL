\begin{abstract}
We present a recurrent network of eight Boolean MUX units with discrete connections, registered state, and a trainable enable route for each unit. Training retains the lexicographic \emph{argmin} criterion of binary-global BFL: it minimizes total errors first, then new errors on previously correct predictions, and finally the number of changed configuration bits. Across five seeds of a cumulative parity task, the \texttt{rbfl\_used\_m\_trainable\_feedback} variant reached 100\% bit and exact sequence accuracy on 400 sequences of unseen lengths and another 100\% on 400 sequences with a shifted distribution. The Elman RNN control reached 81.08\% $\pm$ 19.31\% bit accuracy on the unseen-length test. The ablation with trainable gating but no temporal persistence reached 54.92\% $\pm$ 1.61\%. The success is specific to this construction: on the historical static task, the evaluated RBFL variant reached 73.44\%, below the 90.00\% of binary-global BFL and the 99.29\% of the MLP. We provide code, deterministic splits, per-seed results, and the limits of this comparison.
\end{abstract}

\section{Scope and provenance}
The reference result for binary-global BFL is 90.3066\% mean test accuracy across 50 seeds, archived in commit \texttt{53c2f46}. We recompiled that commit's benchmark unchanged: across 20 seeds, it produced 90.6132\% $\pm$ 1.6145\%. The original model uses 32 routes selected by five input bits, 16 Boolean features, and a majority vote of active features. Training enumerates proposals of up to three bit flips, masks them with the current example's \texttt{USED} features, and evaluates the entire training group for that route. It compares $(\mathrm{ERR},\mathrm{FORGET},\mathrm{CHANGE\_COST})$ lexicographically. In that code, \texttt{CHANGE} denotes a configuration proposal; it is not the error mask.

This study evaluates a different architecture with explicit temporal memory. Accordingly, \emph{winning variant} means only the best RBFL measured on the temporal parity task under this protocol; it does not imply superiority on static tasks or real data. The row identifiers are:
\begin{itemize}
\item \texttt{rbfl\_used\_m\_trainable\_feedback}: parity winner;
\item \texttt{rbfl\_used\_m\_fixed1\_feedback}: fixed-gate control;
\item \texttt{rbfl\_used\_m\_trainable\_no\_feedback}: memory ablation.
\end{itemize}

\section{RBFL architecture}
The state has eight bits, $H_t=(Q_{1,t},\ldots,Q_{8,t})$. Each $A_{i,t}$ and $B_{i,t}$ input selects one of twenty sources: constants 0 and 1, the ten bits of $X_t$, or the eight bits of $H_t$. Every unit reads the same $H_t$ before $H_{t+1}$ is written, so there are no combinational cycles. For each MUX,
\begin{align}
M_{i,t} &= (A_{i,t}\land\neg Q_{i,t})\lor(B_{i,t}\land Q_{i,t}), \\
Q_{i,t+1} &= Q_{i,t}\oplus\bigl[\UM{}_{,i,t}\land(Q_{i,t}\oplus M_{i,t})\bigr].
\end{align}
In the winning variant, $\UM{}_{,i,t}$ also selects a Boolean source from those twenty choices. Its value does not depend on the target during inference. The output is a selected bit of $H_{t+1}$, optionally inverted. The initial state is zero and resets between sequences, while persisting across steps within a sequence.

The usage mask records $U^A_{i,t}=\UM{}_{,i,t}\land\neg Q_{i,t}$ and $U^B_{i,t}=\UM{}_{,i,t}\land Q_{i,t}$. These observations are aggregated into $\UG$ across training trajectories. The search also evaluates rewires of inactive routes; otherwise, a never-used route could not be discovered. Each source index occupies five bits, and a rewire's cost is the Hamming distance between the old and new indices. The winning variant has 124 trainable configuration bits and occupies 44 bytes as a measured C++ object.

\section{Lexicographic greedy search}
We define $\CE=P_{\theta}(X)\oplus Y$, separately from the proposed parameter change $\Delta$. Each candidate resets $H_0$, replays the \emph{entire} collection of training sequences, and obtains $E_\Delta=Y\oplus P_{\theta_\Delta}(X)$. With $E_0=Y\oplus P_\theta(X)$, the implemented criterion is
\begin{equation}
\Delta^*=\operatorname*{arg\,min}^{\mathrm{lex}}_{\Delta}
\left(\sum E_\Delta,\;\sum(\neg E_0\land E_\Delta),\;
\operatorname{popcount}(\theta\oplus\theta_\Delta)\right).
\end{equation}
The current model is compared with the tuple $(\sum E_0,0,0)$; a proposal is retained only if it improves that tuple, and is otherwise reverted. RBFL uses no gradients, SGD, Adam, or floating-point weights. The search tries one complete rewire or one output or initialization edit per candidate, for up to four greedy iterations. This neighborhood differs from the historical BFL's flips of up to three feature bits. \texttt{FORGET} only breaks ties after total errors are equal.

\section{Experimental protocol}
The historical static benchmark contains all 1,024 distinct ten-bit vectors, shuffled with \texttt{std::mt19937(seed)} and split into 600 training and 424 test examples. A second split of the same domain reserves 600/200/224 for training, validation, and test. We retain binary-global BFL from the historical commit and a 16-hidden-unit MLP with 193 \texttt{float64} parameters, 500 Adam epochs, and a learning rate of 0.03. The Elman RNN control has eight hidden units and 161 \texttt{float64} parameters; it uses full BPTT, Adam, 500 epochs, and a learning rate of 0.01.

In the temporal task, the relevant bit $x_{t,0}$ is a fair Bernoulli variable and the other nine bits are distractors. The target is $y_t=\bigoplus_{s=0}^{t}x_{s,0}$. Each seed generates 160 training and 40 validation sequences of lengths 4--8. The final test contains 80 sequences of lengths 9--12 and a separate shifted test of 80 sequences of those lengths with $\Pr(x_{t,0}=1)=0.2$. There are five seeds. The final temporal test uses a separate random stream fixed after preliminary exploration and before these figures were obtained. RBFL parameters are not optimized on test data.

Inference metrics exclude reading and tokenization: they use 10,000 warmup calls and five batches of 100,000 calls, each for a complete sequence. Nanoseconds per step divide the time by mean sequence length. Persistent memory is the model object; temporary memory is a lower bound for inference data, excluding allocator metadata. Measurements use \texttt{g++ 13.3} with \texttt{-O3 -march=native} on an AMD Ryzen 7 5700U. CPU instruction counters were unavailable.

\section{Discussion and limitations}
The task favors a compact Boolean solution: input-dependent gating can implement a conditional toggle of Q. This suggests a plausible mechanism, but does not establish an advantage for the architecture on other memory problems. We measured five seeds and one synthetic temporal rule; we did not test noisy sequences, real data, or an exhaustive hyperparameter search. The architectures do not share parameter or training-time budgets, so the cost comparison characterizes these particular implementations. The RNN has gradients and greater nominal capacity, while RBFL faces a discrete search limited to one change per iteration. Memory figures omit allocator overhead; timing depends on the machine and code. Historical BFL has no comparable temporal state and therefore is not a parity control with memory.

Implementation tests checked all four truth-table rows for both Q values, simultaneous updates across units, retention when $\UM=0$, temporal persistence, recording of the selected A and B routes, and the identity $\CE=P\oplus Y$. A training test verified that a useful proposal changes parameters and that no positive-cost edit is accepted when error is already zero. All 120 rows of the final trace satisfy $\mathrm{ERR}_{\mathrm{best}}\leq\mathrm{ERR}_{\mathrm{before}}$. The RBFL inference executable receives inputs only; labels appear only in supervised evaluation.
